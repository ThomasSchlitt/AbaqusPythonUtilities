# Abaqus Python Utilities
This repository holds a collection of python scripts that have been developed to help automate select repetitive tasks
This repository has been separated into three primary categories:
1. Preprocessing
2. Analysis
3. Postprocessing

Each script should contain a "Usage" doc-string indicating how to utilize the script, either via the command line interface or run through the Abaqus/CAE GUI
If a script has been labeled with INTERACTIVE USAGE, user may copy the function into their abaqusMacros.py file (home or working directory) and access using the Macro Manager within Abaqus/CAE

This repository may contain some small, single-purpose plugin scripts as developed using the AFX Toolkit; however, more complex plugins will be housed in their own repostory
